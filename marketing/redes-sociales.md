# Kit para crear Facebook e Instagram de ChloeRestaurant

Borrador para copiar y pegar al crear las cuentas. Tú haces el alta (Meta pide un correo o teléfono
tuyo y verificación); esto solo ahorra tener que redactar todo desde cero.

## Antes de empezar

- **Correo dedicado recomendado:** algo como `redes@chloerestaurant.lat` o uno nuevo de Gmail, en vez
  de tu correo personal — así el acceso queda separado de tu cuenta y lo puedes compartir con quien
  maneje las redes más adelante.
- **Facebook primero:** Instagram para una marca normalmente se crea/vincula desde una Página de
  Facebook ya existente (Meta Business Suite), así que conviene hacer la Página de Facebook antes.

## Biografía corta (Instagram, ~150 caracteres)

```
Sistema POS para restaurantes 🇩🇴 | Mesas, cocina (KDS), caja y facturación DGII en un solo lugar | Solicita una demo 👇
```

## Descripción larga ("Acerca de", Facebook)

```
ChloeRestaurant es un sistema punto de venta para restaurantes en República Dominicana: mapa de
mesas en vivo, comandas desde PC, tablet o celular, pantallas de cocina y bar (KDS), caja con
comprobantes fiscales (NCF, ITBIS) y reportes 606/607 para la DGII, e inventario y turnos del
personal, todo en un solo sistema.

Conoce más y solicita una demostración: https://chloerestaurant.lat
```

## Primera publicación (Facebook e Instagram)

Usa una de las imágenes de `marketing/anuncios/` (ya tienen texto y son 1200×628 o 1080×1080,
tamaños que ambas redes aceptan bien) o `marketing/capturas/landing.png`.

```
Tu restaurante, bajo control desde la primera mesa. 🍽️

ChloeRestaurant conecta todo: mesas, comandas, cocina y bar, caja y facturación DGII, en un solo
sistema pensado para restaurantes dominicanos.

👉 Solicita una demo: https://chloerestaurant.lat

#RestaurantesRD #POS #SistemaParaRestaurantes #RepúblicaDominicana
```

## Después de crear las cuentas

1. Publica la primera entrada con el enlace de arriba: es el primer enlace entrante real hacia el
   dominio.
2. En Instagram, agrega el enlace en la bio (el feed no permite enlaces clicables en cada post).
3. Dímelo y te ayudo a revisar/ajustar los textos, o a preparar el resto del calendario de
   publicaciones cuando quieras.
